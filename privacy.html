Short prototype language for the marketing site. App-specific policies live with each product listing.

On-device first

Our apps are designed so your work orders, logs, photos, and inventory primarily live on your device. Features that need the network (radar tiles, marine weather, tides) call public data services. We do not run ad networks inside the apps.

What this website collects

This static marketing site does not require accounts. If hosted on GitHub Pages, GitHub may process standard server logs. Email you send to us is voluntary correspondence.
